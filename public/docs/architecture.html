Important Design Choices

JSON-backed domain data

Much of the exam content is stored as JSON instead of normalized tables. events.event_courses, events.external_event_courses, exams.student, exams.exam_courses, and exams.attempts are JSON columns or file-backed structures converted to model objects by Eloquent accessors.

File-backed live attempts

Live exam attempts are tracked in public/exams/exam_{exam_no}.edr. The database receives final attempts during evaluation through Exam::markAsEnded().

Raw PHP public scripts

Files in public/exam-route do not bootstrap Laravel. They directly require ExamHandler and ExamProcess. Any change there must preserve this minimal runtime unless the bootstrap strategy is intentionally redesigned.
