Dependencies

PHP dependencies include laravel/framework, guzzlehttp/guzzle, Pest, Laravel Sail, Pint, Tinker, Mockery, Collision, and Ignition. Composer autoloads app/helpers.php.

Node tooling includes Vite, Laravel Vite plugin, Axios, Prettier, and @prettier/plugin-php. package.json exposes dev and build scripts only.

Tests

Tests are Pest-based. tests/Pest.php binds feature tests to Tests\TestCase and uses DatabaseTransactions.

  • tests/Feature/Helpers/ExamHandlerTest.php covers exam file sync, attempt recording, file ending, time elapsed detection, and valid content loading.
  • tests/Feature/Http/Controllers/Admin/EventControllerTest.php covers event index/show/sync/refresh/evaluate/download/upload and event-wide time extension using HTTP fakes from FakeData. FakeData::run() also writes the sample institution JSON so verify.institution allows admin routes during tests.
  • tests/Feature/Http/Controllers/API/ExamControllerTest.php covers starting an exam, validation failure for unknown exam number, and startup failure for ended exams. The setup creates the event content folder because startup requires downloaded content.
  • tests/Unit/ExampleTest.php and tests/Feature/ExampleTest.php are scaffold examples.

Factories and Sample Data

Factories exist for users, events, exams, courses, course sessions, event courses, exam courses, questions, students, and topics. Some factory methods reference older relationships that may not exist on the current JSON-backed models, so inspect before reusing in new tests.

public/sample-data contains JSON payloads consumed by FakeData for HTTP fakes: sample institution, list events, single event, deep event, and list exams.
