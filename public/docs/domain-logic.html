Actions

ActionMethodsBehavior
InstitutionHandlergetInstance, save, deleteFile, isRecorded, getInstitution, processInstitutionCodeSingleton manager for public/institution-data.json. Converts stored institution array into an Institution model.
SyncEventsmake, all, single, saveToFileSyncs event records from remote and writes event content, course session JSON, exam JSON, and images to public/content.

EndExammake, endEventExams, endExamScores active exams from local attempts. Refuses ended and non-active exams.
ExtendExamTimemake, runReactivates exam, extends end_time, clears pause time, and syncs tracking file.

FakeDatarun and private HTTP fake buildersRegisters HTTP fakes for tests using JSON payloads in public/sample-data.

ExamHandler

MethodDetails
syncExamFile(Exam $exam, $forStart = true)Creates or updates public/exams/exam_{exam_no}.edr. During start, a missing file is acceptable; other read errors fail.
attemptQuestion(array $studentAttempts, $examNo)Merges attempts by question id into the existing tracking file.
endExam($examNo)Marks only the file's embedded exam payload as ended. Database scoring is handled by EndExam.
saveFile($filename, $content)Writes pretty JSON. Kept public for tests/mocking.
deleteFile($examNo)Deletes local .edr tracking file.
calculateScoreFromFile(Exam $exam, $questions)Counts questions where saved attempt exactly equals Question::answer.
getFullFilepath($examNo)Returns public/exams/exam_{examNo}.edr.
getContent($examNo, $checkTime = true)Loads tracking file. With time checks enabled, fails if current time is after embedded end_time or embedded status is ended.
getExamTrack($file)JSON-decodes tracking file.
getExamFileData($examNo)Returns only embedded exam data from tracking file.

Support Classes

ClassPurpose
ContentFilePathBuilds paths under public/content/event_{id}: base folder, images/, exams/, exam_{exam_no}.json, and course_session_{id}.json.
ExamProcessFluent result object for exam file operations. Carries success, message, file path, exam track, time elapsed flag, exam-not-found flag, score, and question count.
ResArrayObject-style result wrapper used by actions and global successRes()/failRes().
WebsiteHelperRemote platform client. Uses institution data to create a PlatformUrl and exposes event list/show/deep-show, exam list, upload, and deep-show-by-code calls.
PlatformUrlAbstract URL contract and factory. Chooses EdumanagerUrl or MockExamscholarsUrl.
EdumanagerUrlBuilds URLs under https://edumanager.ng/api/offline-mock/institutions/{code}/.
MockExamscholarsUrlBuilds URLs under https://mock.examscholars.com/api/institutions/{code}/.

Global Helpers

app/helpers.php is autoloaded by Composer. It provides currentUser(), randomDigits(), pageTitle(), addSpacing(), successRes(), failRes(), form error HTML, JSON debug helpers je()/dlog(), paginateFromRequest(), currentInstitution(), and http().

http() disables SSL verification with withOptions(['verify' => false]). Preserve this only if the deployment environment requires it.
