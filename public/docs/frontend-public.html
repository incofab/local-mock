Frontend Assets

resources/css/app.css, resources/js/app.js, and resources/js/bootstrap.js are Vite scaffold entry files. Admin pages currently load public Bootstrap, jQuery, and Font Awesome assets directly from public/lib.

The static examiner frontend is already built under public/examiner, with static JS/CSS bundles, manifest, Electron file, favicon, robots file, and local libraries.

Public Exam Scripts

ScriptBehavior
public/exam-route/exam-route-base.phpSets CORS and JSON headers, handles OPTIONS preflight, includes ExamHandler and ExamProcess, defines emitResponse() and dlog().
public/exam-route/attempt-question.phpReads JSON input, gets exam_no and attempts, calls ExamHandler::attemptQuestion(), and returns success/failure arrays.
public/exam-route/end-exam.phpReads JSON input, calls ExamHandler::endExam($examNo), and returns success when the file update works.
public/exam-route/exam-img.phpServes images from public/content/event_{event_id}/images/session_{course_session_id}_{filename} with JPEG content type.
These scripts are not full Laravel entry points. They only require direct class files. Do not add Laravel-only dependencies here without changing the bootstrap strategy.
