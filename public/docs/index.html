Purpose

This project is an offline/local mock exam management system. It registers an institution, syncs events from a remote platform, downloads event content, creates and starts exams, tracks attempts in local files, evaluates scores, and uploads completed exam results.

The stack is Laravel 10, PHP 8.1+, Blade admin screens, Pest tests, Vite scaffolding, and a bundled static examiner client with raw PHP endpoints under public/exam-route.

Core concepts: Institution Event Course Session Exam Exam Course Question Attempt

Quick System Summary

  1. InstitutionHandler stores local institution setup in public/institution-data.json.
  2. WebsiteHelper and PlatformUrl fetch events, event content, exams, and upload results.
  3. SyncEvents and EventExamsHandler download event content into public/content/event_{id}.
  4. API\ExamController creates exams by event code and starts or resumes exams for the examiner client.
  5. StartExam marks exams active and asks ExamHandler to create/update public/exams/exam_{exam_no}.edr.
  6. public/exam-route/attempt-question.php records attempts directly into the .edr file.
  7. EndExam scores active exams by comparing file attempts with downloaded question answers.
  8. EventExamsHandler::uploadEventExams() sends completed local exam records back to the remote platform.
